# Cortex 移动端 UI 设计

更新日期：2026-11-04。本文描述当前移动端的整体结构、信息层级与交互约定，包含安全区与提醒修复、任务筛选与手势，以及本次紧凑布局调整。

## 1. 目标与适用范围

移动端首先呈现任务、日期与进度。高频操作常驻，低频设置收进二级菜单；压缩容器留白和重复工具条，同时保留可点击区域与可读性。

- 小于 768 CSS px 使用移动布局；桌面继续使用较宽的文字工具栏。
- iPhone 原生包与手机浏览器使用同一套响应式页面。原生包加载本地资源，网络连接与系统通知由原生能力补充。
- 列表、导图、四象限、甘特图、日历共享任务与时间语义，切换展示方式不复制任务。
- 收起提示、隐藏入口、筛选任务都只影响展示，不删除用户数据。

## 2. 页面骨架与安全区

页面从上到下为：系统顶部安全区、全局工具栏、任务页两行工具栏、可滚动工作区、移动底栏、系统底部安全区。

```text
┌──────────────────────────────────┐
│ 状态栏安全区                      │
│ ☰                      搜索 撤销 重做 │
├──────────────────────────────────┤
│ 当前任务       列 导 象 甘 日    ⋯   │
│ 本周      ‹     11/2 — 11/8    ›  │
├──────────────────────────────────┤
│ 任务／进度条／日历内容              │
│                                  │
├──────────────────────────────────┤
│ 当前任务       首个快捷视图      ＋  │
│ Home indicator 安全区             │
└──────────────────────────────────┘
```

示意中的五个视图在界面上使用图标，保留完整的可访问名称；文字标题过长时省略，不挤掉图标与更多按钮。

### 安全区只有一个所有者

- 网页根容器统一处理四向 `safe-area-inset-*`，根高度跟随可见应用高度。
- 原生 WKWebView 使用 `contentInset: never`、`scrollEnabled: false`。各个内容面板负责内部滚动，整个应用外框不随列表滚走。
- 键盘使用原生调整高度；原生环境读取 `innerHeight`，避免再次扣除键盘高度。浏览器环境跟随 `visualViewport`；捏合放大时不重排应用框架。
- 侧栏与遮罩固定覆盖整个应用可视高度，背景延伸到状态栏与底部安全区；导航内容在侧栏内部避让安全区。
- 底部只压缩额外排版空间，不裁掉 Home indicator 所需的系统安全区，不给底栏重复添加安全区。

### 紧凑尺寸

| 元素 | 移动端约定 |
| --- | --- |
| 全局工具栏 | 40 px 高；桌面维持 48 px |
| 任务标题、视图与更多 | 48 px 行高；视图与更多按钮至少 32 × 32 px |
| 日期范围工具栏 | 40 px 行高；同一行显示范围、区间与前后翻页 |
| 移动底栏 | 48 px 内容高度，较原 56 px 收紧 8 px |
| 甘特图名称列 | 默认 128 px，可调 104–208 px |
| 甘特图任务行 | 34 px 内容加 1 px 下边框；名称与进度条中心对齐 |
| 原生表单输入 | 粗指针设备至少 16 px 字号，避免 iOS 聚焦放大 |

小字号主要用于日期摘要、辅助说明与状态；输入字号和触摸操作区域不能随之无限缩小。

## 3. 导航与信息层级

### 侧栏

侧栏承载当前任务、项目目录、快捷视图，以及复盘、专注、习惯、设置等功能。项目目录可折叠；偏好按账号保存在本机，创建项目后自动展开。

移动侧栏和底栏不再单列「收集箱」。收集箱页面和原有任务仍保留，通过任务页「更多」菜单访问；快速收集按钮继续提供随手录入能力。

### 底栏

底栏保留当前任务、第一个快捷视图和快速收集。其余快捷视图在侧栏中访问。名称较长时截断，完整名称保留在可访问文本中。

### 任务页第一行

标题后紧跟列表、导图、四象限、甘特图、日历五个图标，末尾为省略号菜单。当前视图有明确选中态。项目标题可打开项目详情。

移动端把以下低频操作放进「更多」：

- 隐藏／显示已完成任务。
- 保存为快捷视图。
- 模板。
- 收集箱。
- 项目操作与项目完成进度（项目工作区）。

常驻第一行不再放整段「隐藏已完成」复选框和「模板」文字入口。桌面继续保留常用文字操作。

### 任务页第二行

时间范围选择与当前起止日期在同一行，左右箭头翻动当前区间。日期使用紧凑摘要；点击摘要进入二级日期编辑，取消不改变原区间。自定义区间最长 366 天。

当前年内的区间使用月／日；非当年或跨年时显示短年份，避免短日期歧义。取消、Escape 或应用后焦点回到发起的范围选择器／日期按钮；从更多菜单保存快捷视图时，焦点进入保存对话框，结束后回到更多按钮。

原生下拉框保留系统选择方式、明确箭头和边缘留白。日期编辑中保留完整开始／结束字段与可访问标签，不为了省空间把可编辑输入缩到 iOS 会自动放大的字号。

## 4. 任务与时间语义

### 当前任务

- 所有五种视图隐藏没有 `startAt` 和 `dueAt` 的未排期任务，包括「全部时间」。
- 树形视图保留已排期任务所需的项目／祖先路径，避免子任务失去层级上下文；这些上下文不产生虚构的排期条。
- 不提供全局「未排期」选项、导图「重要未排期」聚焦入口或甘特图未排期底栏。
- 旧的全局 `scope=undated` 链接回到本周；已经删除的快捷视图 ID 不能绕过当前任务筛选。
- 原始任务不因隐藏而删除，项目和有效快捷视图仍可查看未排期任务；原收集箱条目从二级入口访问，不会把未排期任务自动移入收集箱。

### 项目与快捷视图

项目保留全部原始任务，项目之间独立记忆展示方式。快捷视图保存名称、展示方式、项目与默认日期范围；页面内的临时调整不会自动改写快捷视图的默认配置。

相对范围「今天／本周／本月」随日期更新；自定义起止日期固定。快捷视图支持编辑、排序与移除，配置随账号同步；移除入口不删除任务。最多保存 50 个，名称最多 60 字。

### 日期与新建任务

时间筛选按任务开始／截止区间与所选区间是否重叠判断。所选区间包含今天时，新建任务默认今天；否则使用区间首日。当前任务「全部时间」下新任务也默认今天，避免创建后立刻隐藏；项目和快捷视图的全部时间／未排期模式不强制设置日期。

甘特图按当前区间天数翻页；日历自然月按自然月翻页。日期运算使用日历天，跨夏令时不按固定毫秒数强行换算。

## 5. 手势分工

同一手势只由一个功能处理。具体工作表面优先于全局导航；多指、输入、文本选择与系统滚动不应触发额外动作。

| 起手位置 | 手势 | 行为 |
| --- | --- | --- |
| 普通内容空白、工具栏空白 | 向右滑 | 侧栏跟手展开，松手后打开或回弹 |
| 甘特图时间区域 | 单指水平滑动 | 浏览时间轴；到边缘后继续滑动按当前区间翻页 |
| 甘特条或两端把手 | 拖动 | 调整该任务时间，优先于翻页 |
| 甘特名称列分隔线 | 水平拖动 | 调整名称列宽度，优先于翻页与侧栏 |
| 普通列表／甘特图 | 竖向滑动 | 内容内部滚动 |
| 导图画布、日历创建区域、其他横向工作区 | 各自手势 | 保留画布平移、框选或日程操作 |
| 详情正文未到顶部 | 向下滑 | 先滚动正文 |
| 详情正文到顶后继续下拉 | 松手 | 达到阈值后收起详情，距离不足则回弹 |

按钮、输入框、任务行、链接、弹窗、正在选择的文字与多指触摸不用于唤出侧栏。甘特图区域不同时唤出侧栏。侧栏保留显式打开按钮，单次手势失败后不妨碍点击入口。

### 侧栏动效

点击导航按钮时，侧栏用 160 ms 从左侧滑入，遮罩同步淡入。空白区域右滑提供实时位移反馈，不必等手指离开才突然出现；松手按意图与位移完成展开或回弹。小幅竖向抖动不会立即取消已经明确的横向操作，正常竖向滚动仍优先。

当前识别参数：移动 10 px 且水平距离大于竖向的 1.15 倍时锁定横向；松手位移达到 48 px 即完成。明确的快速滑动允许 24 px 起触发（32–260 ms、平均速度至少 0.35 px/ms）。未锁横向前，竖向先行 16 px 且超过水平的 1.25 倍时交给滚动；锁定后允许自然抖动，不使用固定 700 ms 超时。

关闭时反向滑出；点击遮罩、按 Escape 或导航到其他页面均可关闭。系统「减少动态效果」开启后立即切换，跟手拖动仍反映手指位置。

## 6. 甘特图

### 可视空间

名称列默认由 208 px 收到 128 px，把更多宽度留给日期和进度条。拖动列边界可在 104–208 px 之间调整，设置保存在本机；键盘也可调节，双击恢复默认。移动缩进有上限，深层任务不会因多层空白把标题挤没。

任务行中的勾选按钮使用 32 px 高、28 px 宽的触摸区域，图形圈保持轻量；名称列不再因全局表单的最小触区被撑高，任务名、勾选圈与进度条垂直中心保持对齐。

移动周视图优先按可用宽度适配，天宽下限 28 px（桌面 44 px）；窄屏、名称列增宽、更长区间或放大后允许横向浏览。移动缩进每层 8 px、最多 16 px。缩放控件保留在 36 px 工具行中，辅助图例与桌面手势长说明不占据移动端常驻多行空间。

### 时间轴与任务操作

- 左滑浏览更晚的日期，右滑浏览更早的日期；区间有溢出时先平移，达到边缘后继续滑动才翻前后区间。
- 横向锁轴要求移动至少 12 px、水平距离超过竖向的 1.5 倍；边缘额外拉动 56 px 后松手翻页，或额外拉动 32 px 且在 220 ms 内以至少 0.5 px/ms 完成快速滑动。一次触摸最多翻一页，松手最终位置参与判断。时间轴保留原生竖向滚动和捏合缩放。
- 普通轨道的触摸留给时间浏览，不能同时开始鼠标式拖划排期。鼠标轨道拖划仍可设置日期。
- 条的平移和两端伸缩按 5 分钟吸附，取消手势不落库；点击条或标题打开详情。
- 桌面触控板水平滚动按当前区间翻页，一段滚动及其惯性只翻一页。竖向、近对角线、捏合与正在拖动任务时不翻页；放大后的时间轴可用 Shift + 滚轮平移。
- 条表示任务自身的日期；无日期祖先只作上下文行，不绘制聚合排期条。

条色沿用固定优先级语义：P0 红、P1 橙、P2 蓝、P3 灰；完成态为绿，逾期用红色标记。主题色变化不改变优先级颜色。

## 7. 其他任务视图

- **列表**：优先显示任务标题、层级与必要状态；正文内部滚动，外框与底栏保持固定。折叠与时间筛选不带入无关兄弟任务。
- **导图**：保持根节点、全图与工作聚焦，拖动／框选／缩放由画布负责；当前任务不显示未排期聚焦入口，项目仍可查看原始分支。
- **四象限**：仅呈现匹配任务，不为了补齐树形路径额外放入祖先；优先级颜色与其他视图一致。
- **日历**：同一时间范围选择日／周／月展示。任务截止标记、任务时间块与独立日程仍可见；已有时间块关联的任务即使未设开始／截止，也可从时间块打开详情。日历创建网格保留自身操作，不同时唤出侧栏。

## 8. 任务详情与编辑安全

移动端使用有遮罩的底部详情面板，最高 92vh，正文内部滚动，底部避让系统安全区；桌面继续使用侧边详情。

内容滚到顶部后继续下拉，原始手指位移达到 96 px 后松手收起。只有到顶之后的继续移动才计入阈值；同一根手指可以先滚正文、再接着下拉。标题／把手区域也要服从正文是否到顶的限制。

短拉、反向拉回或取消手势会回弹；收起／回弹时长 180 ms。判断使用松手的最终坐标，不能仅按最后一次移动事件决定。输入控件、按钮、链接、文本选择、多指和横向操作不触发误关闭。

关闭前先结束输入焦点并等待标题、备注等草稿完成本地保存；保存失败时保留面板及编辑状态。用户切换到其他任务后，旧任务的关闭回调不能关闭新任务。

## 9. 习惯、打卡与提醒

### 习惯列表

习惯采用紧凑单列，名称区域展开近 26 周的记录；同一时刻只展开一项。打卡与编辑分开，编辑保留习惯 ID 与历史记录。打卡框根据当日完成次数／目标从下向上填色，达标后显示勾选，并保留次数。

每个习惯可设多个时间，最多 24 个且不重复；提醒按当前累计目标与时间槽判断。排序配置按账号保存，调整排序不修改打卡记录。

### 应用内提示

提示保留「去打卡」「10 分钟后提醒」和「关闭本次」操作。无操作且提示可见 15 秒后，用 250 ms 淡出；用户正在用键盘操作提示时暂停自动收起。

关闭或自动淡出只让当日当前批次保持安静，不自动打卡、不关闭后续时间槽或次日提醒。新到点的习惯仍可提示。

### iPhone 系统通知

由用户主动点击授权按钮申请权限，启动和重排本地通知只检查现有权限。已授权时使用原生本地通知，支持系统横幅、锁屏与后台提醒；点击后验证账号归属并进入相应习惯。

按本地时区预排未来 14 天，最多安排 60 条，给系统每应用 64 条待发送限制留出空间。启动、恢复前台、修改习惯、打卡、权限或账号变化时重排。长时间不打开 App 不会无限续排；其他设备修改的习惯需要同步到本机后才能更新本机通知。

## 10. 视觉、可访问性与状态

- 浅色／深色使用相同几何结构，主题只改变配色；正文、辅助信息与选中状态有明确层级。
- 图标按钮保留可访问名称、键盘焦点与选中态；菜单与日期编辑支持取消和关闭后恢复焦点。
- 下拉箭头、输入边框与禁用态统一；选中视图不单靠图标形状表达。
- 长标题、项目名与快捷视图名截断，完整内容仍可在详情或可访问名称中获取。
- 空状态说明当前范围没有任务，并提供合理下一步；当前任务不再引导用户使用已经隐藏的未排期栏。
- 加载、离线、本地保存失败与通知权限状态保持可见，不能靠缩小布局隐藏重要反馈。

## 11. 数据、离线与发布约束

本地资源与 IndexedDB 支持离线编辑；账号和文档隔离，登录后同步。原生网络负责服务器 Cookie，本地资源来源保持稳定，调整服务器地址不能顺带换掉本地数据库来源。

移动 UI 改动在 `ios` 分支维护，后续按用户安排合入主线。安装更新保留原 Bundle Identifier；更新前备份浏览器数据库与本地配置，安装后首次启动前核对数据，保留上一版可回退安装包。筛选和导航调整不运行清库或迁移删除。

## 12. 验收与维护

| 范围 | 验收点 |
| --- | --- |
| 320／360／390 px 小屏 | 标题、五图标与更多同行；时间范围与摘要同行；无页面横向溢出；工作内容获得足够高度 |
| 安全区与键盘 | 状态栏与 Home indicator 不遮挡操作；侧栏全高对齐；键盘打开时无双重压缩；列表滚动不带动外框 |
| 二级功能 | 隐藏已完成、模板、保存快捷视图、收集箱可访问；菜单关闭与日期取消不误改数据 |
| 手势 | 侧栏跟手与回弹；甘特翻页／平移／条拖动／列宽互不抢占；竖向、多指、输入与文本选择正常 |
| 筛选 | 当前任务五视图隐藏未排期，项目／有效快捷视图保留；已有日历时间块关联不失效 |
| 详情 | 正文到顶才能下拉收起；松手最终坐标正确；立即编辑后关闭仍保存 |
| 提醒 | 手动关闭、延后、空闲淡出及未来提醒正常；原生通知权限与点击归属正确 |
| 桌面 | 原文字工具栏、日期输入、收集箱导航、甘特鼠标排期与触控板翻页保持可用 |

自动化回归在独立临时实例执行，不创建生产测试账号、不修改用户任务。Chromium 的真实触摸注入与 WebKit 的事件回归需要区分；iPhone 安装与启动验证不能替代真机手动触摸体验验收。

主要实现入口：
