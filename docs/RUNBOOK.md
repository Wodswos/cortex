# 部署与构建手册

## 服务与公网

Node.js ≥22.13;推荐 Docker Compose。单进程提供静态 Web、HTTP API 和两条 WebSocket 通道。

```bash
PUBLIC_ORIGIN=https://cortex.example.com docker compose up -d --build
curl http://127.0.0.1:30090/healthz
```

`PUBLIC_ORIGIN` 必须是浏览器实际使用的来源(协议、域名和可选端口)。HTTPS 反向代理需要透传 `/api/sync`、`/api/tmux/attach` 的 WebSocket Upgrade。保留同源访问,无需开放 CORS。Tailscale Serve/Cloudflare Tunnel 也需把此来源设置为其实际 HTTPS 地址;仅给 Node 的 HTTP 端口加 HTTPS URL 不会自动提供 TLS。

`COOKIE_SECURE` 在 Compose 中默认 `true`。本机/受信内网 HTTP 调试可用:

```bash
COOKIE_SECURE=false docker compose up -d --build
```

公网部署保留 Secure cookie,通过 HTTPS 访问。首次注册即管理员,随后注册需管理员在设置页生成邀请码;请先在受控环境创建管理员再开放公网。登录/注册限制每个连接来源 IP 每分钟 20 次,最多 4 个并行密码派生;反向代理后的用户共用该预算,服务端不信任任意 X-Forwarded-For。

数据在 `./data`,升级重建容器不删除数据。`docker logs -f cortex` 查看日志。首次生产页面会预缓存路由 JS/CSS;Service Worker 安装完成后才有离线能力。HTTP 内网 IP 通常不是安全上下文,请使用 HTTPS 或 localhost 测试 PWA。

## 账号与 SSH/tmux

HTTP 操作和终端连接都验证账号,使用当前账号拥有的 `serverId`。管理员身份不会授予其他账号的连接权限。设置页保存 SSH 密码到服务端 vault(AES-256-GCM),客户端仅同步名称、主机与密码是否设置。

密钥连接由部署者将密钥放入以下数据卷目录,目录权限建议 0700、私钥 0600:

```text
data/ssh/<账号 UUID>/id_ed25519
# 或 id_rsa;同目录 known_hosts 保存该账号信任的主机
```

不再挂载宿主机 `~/.ssh`,禁用全局 SSH 配置、默认密钥和 agent。目标格式为 `user@host[:port]`,IPv6 写作 `user@[::1]:22`。两个 Cortex 账号若使用同一远端 UNIX 账号和凭据,远端权限仍相同;需要远端会话隔离时应配置不同的 UNIX 账号/凭据。Cortex 无法隔离远端机器本身授予的权限。

旧客户端档案在账户首次在线时迁入 vault 并移除同步中的明文密码。旧快照、历史客户端及旧备份可能仍包含明文凭据,应更换曾保存的密码并按敏感文件保管旧备份。被删的服务端档案不会由现代客户端自动重建;历史链接可在设置中重新配置。

## 备份和恢复

| 方式 | 覆盖范围与恢复方法 |
|---|---|
| 设置页导出 JSON v2 | 含全部实体、设置与 base64 Yjs 文档,保留因果合并;在设置页导入 |
| 已登录请求 `/api/export` | 服务端实时房间快照,包含尚未周期落盘的变更;设置页可导入此格式 |
| 停服务后备份整个 `data/` | 账号、会话、CRDT、SSH 档案、vault 主密钥及每用户 SSH 密钥 |

`credentials.key` 是 SSH 密码解密所需主密钥,必须和 SQLite 一起备份。任务 JSON 和服务器 `/api/export` **不包含新 SSH 密码/私钥**,单独使用它们不能恢复 SSH 凭据。新环境从 JSON 恢复后需重新配置连接。

```bash
docker compose stop
# 将 data/ 整体备份至受控位置,保留文件权限
tar czf cortex-data.tgz data/
docker compose start
```

文件恢复应先停服务再整体恢复数据卷。旧版纯 JSON 不含因果历史,只补充缺失 ID 和设置,已有实体(包括软删除)不被覆盖。v2 按 Yjs 规则合并,可保留历史之后的编辑。导入先校验全部输入,失败不会只导入前半部分。服务器每 5 秒落盘;断电可能丢失尚未落盘的服务端变更,客户端再次连线时会补齐。不能把同步当成独立备份。

账号数据库保存在浏览器的对应命名空间。登录时匿名数据仅迁移一次,目标持久化成功后才清理源数据。离线启动读取上次账号的本地数据,登出/切换账号停止旧同步和计时器。共享设备上的本地数据仍受浏览器配置文件权限控制,不提供设备端加密。

## 开发与自动验证

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm dev:server
corepack pnpm dev

corepack pnpm typecheck
corepack pnpm test
corepack pnpm build
corepack pnpm --filter @cortex/e2e exec playwright install chromium webkit
corepack pnpm e2e
```

`pnpm test` 包含真实本地 HTTP/WS 测试,使用临时 SQLite 和模拟 SSH 可执行文件,不会访问真实 SSH 主机。E2E 固定使用独立的临时服务,默认端口 39901,可通过 `E2E_PORT` 更改,不会复用已启动实例。Chromium 可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 使用已有 headless shell。不要为测试清理部署的数据卷。

仓库中的旧 `repro-*`、`shot-*`、`e2e/flows.mjs` 等为历史手工诊断脚本,部分假定旧协议或指定测试账号,不属于回归入口;运行前检查脚本目标,仅用于独立测试实例。

## macOS 桌面壳

在装有 Xcode Command Line Tools、Rust 与 Tauri 依赖的 Mac 上:

```bash
corepack pnpm --filter @cortex/desktop dev
corepack pnpm build:desktop
```

桌面包从 `tauri://localhost` 加载内置页面并继续使用该来源的本地数据。使用 macOS 标题栏拖动窗口，按 ⌥Space 聚焦窗口并触发快速收集。

桌面包默认连接 `http://115.190.3.4:30090`，可以在构建时指定其他服务器来源。

```bash
CORTEX_DESKTOP_API_ORIGIN=https://cortex.example.com corepack pnpm build:desktop
```

桌面包通过原生 HTTP 发送账号请求，并将会话 Cookie 保存在 WebKit 的原生存储中。同步和终端 WebSocket 使用同一个服务器地址。服务端为 `tauri://localhost` 来源的 WebSocket 校验一次性会话票据。开发模式通过 Vite 代理连接本机服务。

## iPhone Capacitor 壳

默认打包本地 Web 和本地数据库,使用 `apps/web/.env.mobile` 中的
`VITE_CORTEX_API_ORIGIN` 连接账号服务器。目前对应现有部署
`http://115.190.3.4:30090`。Web 构建仍保持同源请求,不会使用移动端专用地址。

```bash
corepack pnpm --filter @cortex/mobile sync
# 更换原生 App 后端时,构建与 iOS 配置使用同一个环境变量:
VITE_CORTEX_API_ORIGIN=https://cortex.example.com corepack pnpm --filter @cortex/mobile sync
corepack pnpm --filter @cortex/mobile open:ios
```

原生 HTTP 通过 CapacitorHttp 使用系统 Cookie 存储,不把会话令牌写入
localStorage。同步和终端 WebSocket 使用同一个服务器地址,仍需有效的一次性
会话票据。服务端仅为这些带票据的 WebSocket 接受 `capacitor://localhost`
来源;HTTP 来源校验和 Cookie 配置不变。

`sync` 会为显式配置的 HTTP 主机添加单独的 ATS 例外,不会关闭整个 App 的
传输安全校验。IP 地址例外需要 iOS 17 或更新版本。原生工程已存在时会保留
Team、Bundle Identifier 和其他 Info.plist 配置。原生工程本身被 gitignore
排除,因此修改服务器后应再次运行完整的 `sync`。

安全区统一由网页根容器处理。WKWebView 使用 `contentInset: never`、
`scrollEnabled: false`;Keyboard 插件按 `native` 模式调整视图高度。页面内部
列表和登录表单负责滚动,不要给外层页面再加一层安全区或键盘高度补偿。
移动侧栏与遮罩从屏幕顶端覆盖到应用可视区域底端，状态栏及底部安全区使用相同背景；
导航内容在抽屉内部避让安全区，随键盘及可视区域高度变化调整。
移动侧栏以 160ms 从左侧滑入，空白内容区域向右滑动也可打开；任务、控件与横向操作区域保留原有手势。
开启系统「减少动态效果」时侧栏立即切换。任务详情滚动到顶部后继续向下拉，松手即可收起；
距离不足时回弹，编辑内容保存成功后才关闭。正文尚未到顶、文本选择及输入控件操作不会触发收起。

移动任务页使用两行紧凑工具栏：标题、五视图图标与更多在第一行，时间范围与日期摘要在第二行。
隐藏已完成、模板、保存快捷视图及收集箱移入更多菜单；移动导航不单列收集箱。
底栏内容高度由 56px 收至 48px，系统底部安全区完整保留。日期摘要点击后在二级弹窗编辑，应用才修改区间。
总体结构、尺寸、手势、详情、习惯与原生通知的完整设计见 [移动端 UI 设计](MOBILE_UI_DESIGN.md)。

需要加载整个远程网页而非本地资源时,可选择已有的 HTTPS 远程模式:

```bash
CORTEX_MOBILE_URL=https://cortex.example.com corepack pnpm --filter @cortex/mobile sync
# 首次需要生成平台工程:
cd apps/mobile
corepack pnpm exec cap add ios
corepack pnpm exec cap open ios
```

在 Xcode 设置 Team 与唯一 Bundle Identifier,连 iPhone 运行。免费 Personal Team 签名通常 7 天失效。模拟器构建和未签名的真机归档不代表已经能安装到手机;真机安装还需要签名。原生分享入口与通用后台执行仍需接线与设备验证；习惯提醒使用下述 iOS 本地通知，不依赖网页在后台运行。

## 工作空间与导图样式

桌面侧边栏的右边缘可拖动调整宽度（192–360 像素），双击恢复默认；
聚焦分隔条后可用左右方向键微调。宽度保存在当前浏览器，不参与任务撤销。
项目名称左侧的手柄可拖动排序，也可用空格和上下键排序。
手柄与右侧菜单在鼠标悬停或键盘聚焦整行时显示；触屏始终显示，项目整行共享选中背景。
右侧的省略号菜单和右键菜单提供编辑、归档和删除；删除项目前会确认受影响的子项数量，
确认后软删整个项目子树，可用撤销恢复。本地保存成功后关闭确认框。

侧边栏「回收站」显示当前账号已删除的项目和任务，包含旧版本已软删的内容，
支持层级展开、搜索标题或备注、查看和恢复，不自动清空。
恢复项目只恢复同次删除的子项，更早单独删除的任务仍留在回收站；单独恢复子任务时，
同时恢复其所在的必要祖先路径。新删除使用独立批次标识，旧数据按删除时间兼容。
彻底删除和清空回收站均需确认，不能通过撤销恢复；移除相关资源链接，
保留日程及专注历史并解除任务关联。此操作不影响已有独立备份。

导图中 Ctrl/⌘ + A 选中当前可见节点（不包含虚拟“全部任务”根节点），
保留折叠和项目范围；工作强调模式下也包含淡化的上下文节点；编辑标题时仍全选文字。支持框选或按住 Ctrl/⌘、Shift 点选。
选中后点击“样式”，可修改背景、文字颜色、字体、10–32px 字号、粗体和斜体，支持批量调整
和恢复默认。样式按字段随任务同步，包含在两种备份格式中；每次批量调整可单独撤销。

导图默认字体为霞鹜文楷、16px、加粗，所有分支从根节点向右展开。
层级通过留白与背景区分，连线使用同分支的低饱和度颜色；节点手动设置的字体、字号与粗细优先保留。
长标题自动换行、完整显示，布局根据实际文字尺寸调整。“当前工作”等按钮强调任务及其祖先路径，
保留其他分支和节点位置。单击仅选中，双击编辑；Shift + Enter 换行；点击“详情”或
Ctrl/⌘ + Enter 查看任务详情。Tab 添加子任务，Enter 添加同级（项目根节点添加子任务）。

新增 Noto Sans SC、Noto Serif SC、霞鹜文楷、Inter、JetBrains Mono；均为 SIL OFL 1.1，
许可与版权声明随应用发布于 `/fonts/licenses/index.html`。字体文件由应用本身提供，
导图打开时加载默认文楷，其他字体选择使用后加载；中文 Noto 字体按 Unicode 字符子集请求，霞鹜文楷粗体首次加载约 7 MB，文件会由浏览器缓存。
为父节点选择字体后，未指定字体的后代跟随；单个节点仍可覆盖。加载失败时使用系统字体。

小图初次打开适配画布，大图初次打开以可读比例显示根节点附近。平移、缩放自动保存在当前
浏览器，按账号及项目/根节点分别记忆，切换工作强调不重置；不跨设备同步。
右下角统一提供缩放比例、放大缩小、根节点、全图和导图配置；点击百分比恢复 100%，保留当前画布中心。
配置包含连线样式（随账号同步）和双指/滚轮平移速度（0.5×–3×，默认 1×，为旧默认速度的两倍）。
平移速度按账号保存在当前浏览器，跨项目使用，不参与任务撤销；缩放手势不受平移速度影响。
左下角的操作说明按浏览画布、选择与查看、创建与编辑、调整结构分组；配置不再放在说明中。
说明和配置从捕获阶段处理外部点击，点画布空白处、中键、右键或触屏空白处均会收起。
画布和节点悬停使用普通箭头，实际拖动时才显示抓取光标；节点移动超过 6px 才开始拖动，避免轻微手抖修改任务。
选中使用即时细边框，不加粗光晕或移动视口；选中上下文只更新相关分支强调，不重新测量、排列整张图。
普通鼠标按下节点即显示选中，不等待松开；修饰键多选、已选批次拖动和节点内控件沿用各自操作。
鼠标悬浮未选节点时显示半透明外边框，移开自动淡出；选中与悬浮共用相同尺寸的外框，仅加深颜色，按下时即时呈现。
不改变节点尺寸、连线锚点或任务内容，卡片内边框保持原有样式。
点选期间保持画布事件回调稳定，避免无关节点包装器重复渲染；几何完整后，纯视角变化跳过全图检查。
“根节点”返回可读缩放，“全局视图”缩放至全图。窗口或侧栏尺寸变化时保留原视角中心。
重排沿用最近的实际节点尺寸和连接锚点，字体、标题或尺寸变化后由 ResizeObserver 更新，避免连线因测量重置而消失。
布局更新使用最新状态合并已排队的测量和选择，避免字体完成、数据载入时覆盖测量结果。
导图初始化不依赖单次 ResizeObserver 通知；首次进入、容器恢复显示或页面重新获得焦点时，
只为缺少尺寸／连接锚点的节点补测量，同时恢复连线和框选命中范围，不重建画布或重置视角。

## 工作区与时间区间

侧栏将「今天／本周」合并为「当前任务」，默认打开本周甘特图；工作区内选择今天、
本周、本月或自定义起止日期。当前任务的列表、导图、四象限、甘特图和日历均隐藏未排期任务，
包括「全部时间」；仅保留已排期任务所需的项目／祖先上下文。当前任务不再提供「未排期」选项或甘特图未排期栏，
旧的当前任务 `scope=undated` 链接转到本周。原始任务不删除，项目与已有快捷视图仍可查看未排期内容。
视图统一从工作区顶部切换，原「时间线」统一命名为「日历」。
原 `/calendar` 入口重定向到全局本月日历，旧 `view=timeline` 链接和项目偏好继续有效，
也兼容 `view=calendar`。全局日历同时显示任务和独立日程，项目日历只显示对应项目内容。
旧的任务、scope、view 深链接继续可用；时间区间保存在 URL，切换当前任务视图时保留。
项目仍各自记忆视图；项目列表／导图／四象限默认全图，甘特图／日历默认本周。
日历月视图按自然月翻页，跨月保持月格；甘特图继续按当前区间的天数翻页。
月历按单元格高度保留可见项目，其余显示「还有 X 项」；点击打开当天完整任务与日程的
可滚动浮层，支持键盘选择、Escape 关闭及移动端边缘避让。选择任务打开详情，选择日程查看当天。
月历采用紧凑行与日期头，常见桌面尺寸可显示约 3 项、窄屏约 2 项后再折叠；行数继续随可用高度变化。
当天完整列表将名称和类型放在同一行，长标题可换行。
日历新建任务草稿打开后，点击框外只取消当前草稿，该次点击不会再触发底下日期／时间格的新建；
再次点击空白处才开启新草稿，未确认的草稿不写入数据。
时间筛选按开始／截止区间重叠匹配，树视图保留祖先路径，避免项目中的子任务失去上下文；
四象限只显示实际匹配的任务。所选区间包含今天时，新任务默认排在今天；否则排在区间首日，
当前任务的全部时间模式下，新建任务默认排在今天，避免创建后立即隐藏；项目／快捷视图的全部时间与未排期仍不自动设日期。
自定义区间最长 366 天。项目目录可收起／展开，偏好按账号保存在当前浏览器，创建项目后自动展开。

侧栏「快捷视图」默认提供「本月日历」，可添加或从工作区顶部的书签按钮（手机为更多菜单）保存配置，
包括名称、展示方式、项目范围、默认时间范围和任务筛选；支持编辑、拖动排序和移除。移除只影响入口。
今天／本周／本月是随日期自动更新的默认值，固定日期区间则保留具体起止日期；每次从侧栏
打开会恢复保存的配置，页面内临时调整不会自动改写默认值。绑定项目的快捷视图不改写该项目的独立视图偏好。
配置随账号同步并包含在备份中，最多 50 个，名称最多 60 字。移动底栏显示第一个快捷视图，其余从侧栏访问。
快捷视图目录和项目目录可独立收起／展开，状态按账号保存在当前浏览器；确认新增快捷视图后自动展开。
全局导图的共同根节点使用当前用户名，未登录时显示「我的工作空间」；它仅用于展示，不写入任务数据或改名实际项目。
所有原生单选下拉统一箭头大小、边缘留白和文字内边距，保留原生键盘与触屏操作。

手机甘特图名称列默认 128px，可拖动分隔线在 104–208px 调节并在本机保存；桌面仍为 208px。
手机单指横滑先平移溢出的时间轴；从内部首次滑到边缘只停在边缘，继续拉动或快滑也不翻页。
必须松手后从对应边缘重新起手向外滑动，才按当前区间翻页；整周无溢出时仍可直接翻页。普通轨道触摸不同时启动排期。
侧栏在其他普通空白区域右滑时跟随手指展开，松手后完成打开或回弹；甘特图、日历创建网格和导图各自保留手势。
桌面甘特图双指左右滑动按当前显示天数翻页（例如 7 天、1 天或自定义区间）；按日历日期计算，
跨夏令时不漂移。一次手势及其惯性只翻一页；纵向／近对角线滚动、捏合缩放和任务拖动不触发翻页。
放大后的时间轴可用横向滚动条或 Shift + 滚轮平移，也可用区间两侧的箭头翻页。

五个视图共用「全部／当前工作／本周／逾期」、时间区间和更多筛选（状态、优先级、标签）。
「进行中」仅指手动标记为 doing；「当前工作」为进行中或未完成逾期的并集，不限制历史日期。
「本周」为按账号起始日设置计算的自然周，匹配任务日期或关联日程；不自动改变任务状态。
快捷按钮重新设定工作与日期范围并清除额外条件；更多筛选和日期范围按交集计算。
切换展示视图保留全部条件；从侧栏重新打开快捷视图恢复其保存配置，旧配置继续兼容。
列表／甘特保留匹配任务的祖先行，祖先本身不匹配时不绘制甘特条；四象限与日历不加入祖先。
导图在日期筛选后的树中淡化不匹配分支，保留布局、连线和全局上下文。
甘特／日历的全部时间筛选保留匹配集合，有限画布按匹配日期打开（甘特最多展示 366 天，
日历打开靠近匹配日期的月份）；区间输入旁以「画布」说明。手动翻页／改日期会设定新的日期筛选。
项目和快捷视图的未排期任务保留在甘特底部和日历未排期栏；日历支持仅有开始日期的任务。
任务菜单「清除日期」同时清除开始与截止日期，支持批量操作、一次撤销和本地持久化；
不改动子任务或关联日程。详情中单独日期字段的清除按钮只清除对应字段。

## 习惯与提醒

右上角可切换「按提醒时间／手动排序」，默认按配置时间从早到晚排列，未设置时间的排在最后，
相同时间按手动顺序排列。行左侧把手支持鼠标、触屏拖动，或按空格后用上下键排序；
确认拖动后自动切换手动排序，取消拖动不写配置。切回按时间排序保留此前的手动次序；
修改时间会实时更新按时间排序的列表。排序配置随账号同步并包含在备份中，不修改打卡记录。

习惯按单列紧凑行排列；点击名称区域展开近 26 周的打卡热力记录，再次点击收起，
同一时刻最多展开一项。行内可直接打卡并查看今日次数；右侧铅笔编辑名称、颜色、
频率、每日目标与打卡时间。编辑原地更新，保留 ID、创建时间和全部历史记录；
间隔频率继续从最初创建日计算。编辑表单只保存实际修改的字段，避免覆盖其他设备的无关编辑。

行首打卡框按今日次数／每日目标从下向上填色，达标后显示完整勾选，保留数字计数；
点击未达标的框增加一次，达标后点击撤销一次，展开详情也可逐次撤销。
一个习惯可添加多个打卡时间（最多 24 个，不重复），按最早时间参与排序。
多个时间按比例分配累计目标并向上取整，例如每日两次、08:00／20:00，早间完成一次后
收起提醒，到晚间再提醒第二次；提前完成计入全天目标，错过时间会在当天打开应用时补提醒。
各时间分别记录通知与延后状态；旧单时间设置自动兼容，修改与备份保留历史记录。

时间使用设备本地时区，可单独设置时间而关闭「到时提醒」。有时间的旧习惯未设置提醒开关时默认开启。
应用打开时每 30 秒及恢复焦点／可见状态时检查提醒，全天补充当天已经到点但尚未达标的习惯；
遵循指定星期、间隔天数，弹性每周次数达到累计目标后停止本周提醒，旧 custom cron 不执行提醒。
全局提醒可直接跳到对应习惯并展开记录，也可延后 10 分钟。桌面逐项关闭或延后，手机处理当前一批。
手机应用保持可见且 15 秒没有触控或键盘操作时，提醒用 250ms 淡出。键盘正在操作提醒按钮时暂停自动收起。
关闭和自动收起只让这些习惯当天本次时间的提醒保持安静，不打卡、不关闭后续提醒；稍后新到点的习惯与次日提醒仍正常出现。
延后和收起按账号、习惯、日期和时间保存在当前设备。当天达标后自动收起，次日重新判断。

iPhone 原生 App 使用 Capacitor LocalNotifications。可在「设置 → 通知 → 开启手机通知」或习惯编辑表单中主动授权；
启动应用只查询权限，不自动弹授权框。授权后同时支持应用内提示、系统横幅及锁屏／后台本地通知，
点击系统通知跳转到当前账号对应的习惯并展开记录。被系统拒绝时，需到 iPhone「设置 → 通知 → Cortex」重新开启。
系统专注模式、静音和通知样式仍由用户的 iOS 设置决定。

应用按设备本地日期为未来 14 天生成单次提醒，并保留最早的最多 60 条待发送习惯通知，
为 iOS 的每应用 64 条待发送上限留出空间。启动、恢复前台、修改习惯、完成打卡及权限变化时重排；
关闭提醒、移除习惯及切换／退出账号会移除对应待发送通知，不影响其他类型通知。
后台期间其他设备的修改需本机再次同步后才会影响已经排入 iOS 的通知；长时间不打开应用时，有限的预排队列不会无限续期。
HTTP 公网网页仍只保证应用内提醒；安全上下文且浏览器支持时可以主动开启浏览器通知，关闭网页后不推送。

习惯配置和打卡随账号同步，包含在 JSON／二进制备份中。移除习惯需确认，仅软删除习惯，
保留历史打卡；一次撤销可恢复习惯及其记录。创建、修改和导入前校验时间与频率，
新增草稿取消不写入数据。

## 日报与周报

「复盘」提供日报、周报和时间线。时间线按复盘日期倒序、按月分组展示全部历史
日报与周报（含草稿），支持类型筛选、搜索日期与正文，点击日期查看或继续编辑。
第 02 项「哪里卡住了，为什么？」下增加独立的「如何解决？」输入，随复盘同步、
备份并导出至 Markdown；旧复盘的这一字段默认为空。
草稿随账号同步并包含在 JSON 备份中;
点击「完成复盘」后保存任务与专注汇总快照,继续编辑会恢复为草稿。
默认提醒为设备本地时间每天 21:30、每周日 20:00,可在复盘页面调整或关闭。
提醒在应用打开时检查,未完成的最近一期会在下次打开时提示,可推迟一小时;
不提供网页关闭后的后台定时推送。工作汇总基于当前任务状态与已记录的专注会话,
不是任务状态的历史回放;跨日专注按会话实际时间比例分配。

## 故障排查

Agent REST API 覆盖任务、项目、习惯打卡与复盘；在设置的「Agent API」中创建或撤销
账号专用的只读／读写 Token。Swagger 为 `/api/docs`，OpenAPI JSON 为 `/api/openapi.json`，
具体调用、幂等重试、ETag 和复盘时区规则见 [API.md](API.md)。Token 摘要和 24 小时幂等记录
保存在 SQLite；部署／恢复仍需完整备份 data。业务 JSON 备份不包含 Token。

| 症状 | 检查 |
|---|---|
| HTTP 登录后仍未登录 | HTTP 调试是否显式设置 `COOKIE_SECURE=false` |
| API/WS 403 | `PUBLIC_ORIGIN` 是否等于浏览器来源,代理是否保留 Upgrade |
| API 409 | 页面身份和 Cookie 已变化;重新载入,确认当前账号 |
| 429 | 登录或终端预算已用尽,等待窗口恢复;检查是否共用代理 IP |
| SSH 无法登录 | 当前账号密钥目录、主机/端口、远端账号权限、密码与 known_hosts |
| 离线启动失败 | 是否曾在线完成生产 SW 安装,是否清过浏览器存储 |
| 登录后数据不同 | 检查账号;匿名迁移不会重复复制到后续账号,可从备份恢复 |
| 忘记密码 | 保留完整数据卷和浏览器数据库,先备份;当前没有自助重置接口,勿删除数据重建 |
